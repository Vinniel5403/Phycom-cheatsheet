void onMqttMessage(int size) {
  String topic = mqtt.messageTopic();
  String msg = "";
  while (mqtt.available()) msg += (char)mqtt.read();
  msg.trim();
  if (topic == SID + "/venus") {
    int v = (int)round(msg.toFloat());
    if      (v >= 36 && v <= 50) rgbColor(1, 0, 0); // แดง
    else if (v >= 26 && v <= 35) rgbColor(0, 0, 1); // ฟ้า
    else if (v >= 10 && v <= 25) rgbColor(0, 1, 0); // เขียว
    else                          rgbColor(0, 0, 0);
  }
  if (topic == SID + "/prob_stat") segShowNumber(msg.toInt());
}

7-Segment 1 หลัก (10 ขา)

      
      
มองหน้าจอ (จุด dp อยู่ล่างขวา) · แถวบน: g f COM a b · แถวล่าง: e d COM c dp · ขา COM 2 ขาเชื่อมกันภายใน

      
    
        
  • Common Cathode (เช่น 5161AS): COM → GND, segment HIGH = ติด
    • 
        
  • Common Anode (5161BS): COM → 5V, segment LOW = ติด
    • 
        
  • ทุก segment ใส่ R 220Ω–1kΩ (R4 จ่ายต่อขาได้น้อย)
    • 
        
  • ไม่รู้ชนิด: ต่อ COM→GND, จ่าย 5V ผ่าน R เข้า a → ติด = CC; ไม่ติด ลอง COM→5V, a→GND ผ่าน R
    • 
      

      
2 หลัก (multiplex แบบที่แล็บทำ)

      
ต่อ segment a–g ของทั้ง 2 ตัวขนานกัน (ใช้ 7 ขา) · COM ตัวซ้าย → ขา DIG1, COM ตัวขวา → ขา DIG2 (ห้ามต่อลง GND ตรง) · โค้ดสลับเปิดทีละหลักเร็วๆ (ทุก 3 ms) ด้วย millis/micros ห้ามใช้ delay ยาวๆ ไม่งั้น MQTT ไม่ทำงาน

    •
